# Employee Management System

A complete full-stack employee management system with authentication, role-based access, CRUD operations, and analytics dashboard.

## 🚀 Features

### Task 1: Authentication UI + Dashboard Layout
- Login/Signup page with dark/light mode
- Responsive sidebar with navigation
- Protected routes for authenticated users

### Task 2: Employee Dashboard UI
- Employee listing with search and filter
- Pagination and sorting
- Add/Edit/Delete employees
- Employee details panel

### Task 3: Backend API Setup
- FastAPI backend with RESTful endpoints
- JWT authentication
- SQLite database integration

### Task 4: Frontend + Backend Integration
- Axios API service layer
- Loading states and error handling
- Toast notifications

### Task 5: Database Integration
- SQLite database for persistent storage
- Employee and Department models
- Data persistence after server restart

### Task 6: Complete CRUD Operations
- Add, Edit, Delete employees
- Form validation
- Confirmation modals

### Task 7: Authentication + Role-Based UI
- User registration and login
- JWT token authentication
- Role-based menu visibility (Admin/User)

### Task 8: Analytics Dashboard + Polish
- Statistics cards with trends
- Charts (Bar, Pie, Area, Line)
- Department distribution
- Employee growth tracking
- Responsive design
- Dark/Light mode

## 🛠️ Tech Stack

### Frontend
- React 18
- React Router DOM
- Axios
- Recharts (for analytics)
- React Hot Toast
- CSS Modules

### Backend
- FastAPI
- SQLAlchemy
- SQLite
- JWT Authentication
- bcrypt for password hashing
